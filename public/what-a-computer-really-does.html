Your Computer Is Basically a Very Fast Idiot

It renders movies, runs games, and holds video calls — by doing one mind-numbingly simple thing a few billion times a second.

Here’s a secret that’ll change how you see every device you own: your computer is stupid. Gloriously, relentlessly stupid. It does not “run apps” or “understand” anything. It does exactly one tiny thing — grab an instruction, do it, grab the next — and it does it so blindingly fast that the result looks like intelligence. Once you see the trick, computers stop being magic and start being obvious. Welcome to lesson one.

The dumbest loop in the world

At the heart of your machine is the CPU, and all it ever does is spin one loop:

  1. Fetch the next instruction.
  2. Decode it (add? compare? jump?).
  3. Execute it — usually nudging one or two numbers.

Then back to step 1. Forever. A few billion times a second. Every game, browser, and AI you’ve used is just a monstrously long to-do list of these baby steps. The CPU never knows it’s “playing a video.” It only ever sees: next.

💡
The whole trick

Speed + simplicity, faked hard enough, becomes intelligence. The CPU isn’t clever — it’s just tireless and absurdly fast. Every “smart” thing computers do is millions of dumb steps stacked into a tower. Remember that and nothing in tech will ever intimidate you again.

Why nobody writes billions of instructions by hand

They don’t — they build layers, each one a convenient lie that hides the mess below: raw machine code → languages like Python → the operating system → the app you tapped. When you type print("hi"), you’re standing on a skyscraper of these lies, and at the very bottom floor is that same dumb fetch-decode-execute loop, sweating away. The whole art of software is picking which floor to stand on.

The gist

  • A CPU only ever does one loop: fetch → decode → execute, then repeat.

  • Every program is a giant list of these tiny steps; the CPU sees no ‘big picture’.

  • ‘Intelligence’ is just simple steps run stupidly fast — not cleverness.

  • Software hides complexity in layers, each lying about the one below.

  • print("hi") sits atop a tower that bottoms out in that same dumb loop.
